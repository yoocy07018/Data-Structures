栈的基本知识
栈（Stack）是计算机科学中一种最基础且最重要的线性数据结构。它的核心特征可以概括为一句话：后进先出（Last In, First Out，简称 LIFO）。

这意味着最后存入栈中的元素，必须是最先被取出来的。你可以把它想象成一叠盘子：你只能把新盘子放在最上面，也只能从最上面拿走盘子。

1. 核心操作
栈的操作非常简洁，主要包含以下几个基本动作：

Push（入栈/进栈）： 将一个新元素放入栈顶。

Pop（出栈/退栈）： 移除并返回栈顶的元素。

Top（查看栈顶）： 返回栈顶元素的值，但不移除它。

Empty（判空）： 检查栈中是否还有元素。

IsFull（判满）： 对于有容量限制的栈（如数组实现），检查是否已满。

size (判个数) ： 判断有多少个元素


2. 栈的存储结构
在代码实现中，通常有两种方式来构建一个栈：

顺序存储（顺序栈）
实现方式： 使用数组实现。

特点： 需要预先分配一块连续的内存空间。

优缺点： 访问速度快，但容量固定。如果数组满了，需要进行扩容操作（重新分配内存并复制数据）。

链式存储（链栈）
实现方式： 使用单链表实现，栈顶通常对应链表的头节点。

特点： 动态分配内存。

优缺点： 不存在固定的容量限制，更加灵活，但每个节点需要额外的指针空间。

3. 栈的应用场景
栈在算法和系统底层中无处不在，以下是几个典型的例子：

函数调用栈（Call Stack）： 编程语言处理函数嵌套调用时，系统会用栈记录每一层的返回地址和局部变量。

表达式求值： 编译器使用栈来处理括号匹配（如 {[()]}）以及将中缀表达式（1 + 2）转换为后缀表达式（1 2 +）。

浏览器的前进与后退： 浏览器使用两个栈来存储你访问过的历史记录。

深度优先搜索（DFS）： 在图论算法中，栈是实现 DFS 的核心工具。

撤销操作（Undo）： 文本编辑器记录你的每一步操作，撤销时通过出栈回到上一个状态。

4. 注意事项：栈溢出（Stack Overflow）
这是一个非常常见的术语。它通常发生在：

递归过深： 函数不断调用自身且没有正确的终止条件，导致函数调用栈超过了系统分配的内存上限。

局部变量过大： 在栈上申请了过大的数组或对象。

5. 简单代码示例 (C++)
在 C++ 中，如果你不想手动实现，可以使用标准库 std::stack：

C++
#include <iostream>
#include <stack>

int main() {
    std::stack<int> s;

    s.push(10); // 入栈
    s.push(20);
    
    std::cout << "栈顶元素: " << s.top() << std::endl; // 输出 20

    s.pop(); // 出栈
    std::cout << "出栈后新的栈顶: " << s.top() << std::endl; // 输出 10

    return 0;
}
