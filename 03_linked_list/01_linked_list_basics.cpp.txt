————————————————————————————
空指针
在 C++ 里，你不能直接写 null（全小写）。 
nullptr 是现代 C++ 专门为指针量身定制的专属关键字。
在 Java 或 C# 等语言里，空指针确实是用全小写的 null 表示的。
但在 C++ 的标准字典里，根本不存在 null 这个词。
如果你在代码里写 next = null;，编译器会直接罢工并报错：“null”未声明。
在以前的老版本 C++（C++11 标准之前）里，是用大写的 NULL 来表示空指针的：Node* next = NULL;
可是NULL 的真面目是 0（一个整数），不能完全算是一个空指针。
————————————————————————————

我们可以把链表想象成一场寻宝游戏：你拿到的第一张纸条（头节点）上写着一个线索（数据），并且还写着下一张纸条藏在哪里（next 指针）。你必须顺着线索一张一张找，直到最后一张纸条告诉你“没有下一张了”（null）。
————————————————————————————
1. 链表的核心单位：节点 (Node)
链表并不是连续存在于内存中的（不像数组那样挨在一起）。它是通过一个个独立的节点（Node）连接起来的。
每一个节点通常包含两个部分：

数据域 (Data / Value)： 这里存放你真正想要保存的信息（比如数字、字符串或一个对象）。

指针域 (Next)： 这里存放的是下一个节点的内存地址。它就像一根绳子，牵着下一个节点。

————————————————————————————

2. next 是如何把节点串起来的？
我们来看一个最基础的单向链表 (Singly Linked List)：

假设我们有三个节点，分别存着数字 10, 20, 30：

头节点 (Head)： 链表的入口。我们必须知道 Head 在哪，否则整个链表就找不到了。

节点 A (Data: 10)： 它的 next 指向节点 B。

节点 B (Data: 20)： 它的 next 指向节点 C。

节点 C (Data: 30)： 它是最后一个节点，后面没有东西了，所以它的 next 指向 Null（或 None）。Null 是链表结束的标志。

在代码逻辑中，如果你当前在节点 A，你想要获取 20 这个数字，你不能直接跳过去，你必须通过 A.next.data 才能拿到。



3. 为什么 next 如此重要？（链表的增删操作）
链表最大的优势在于插入和删除非常快，而这一切都归功于 next 指针的灵活改变。我们不需要像数组那样移动大量元素，只需要“重新系一下绳子”。

插入节点 (Insertion)
假设我们要在节点 A 和节点 B 之间插入一个新节点 X：

先让新节点 X 的 next 连上节点 B (X.next = B)。

再把节点 A 的 next 断开原来的连接，连到新节点 X 上 (A.next = X)。
就这么简单！其他节点完全不需要移动。

删除节点 (Deletion)
假设我们要删除节点 B，也就是让 A 直接连上 C：

我们只需要找到节点 A。

把节点 A 的 next 直接指向节点 B 的 next（也就是节点 C）。

代码表示为：A.next = B.next。
节点 B 虽然还在内存里，但它已经脱离了链表，随后会被系统的垃圾回收机制清理掉。



4. 总结：链表 vs 数组为了让你更好理解，对比一下你可能更熟悉的数组：
特性                     数组 (Array)                             链表 (Linked List)
内存分配                 连续的内存块。                       零散的内存块，通过 next 链接。
访问元素     极快（可直接通过索引访问，如 arr[5]）。         较慢（必须从头节点顺着 next 一个个找）。
插入/删除      较慢（需要移动后续所有元素）。                极快（只需改变前后节点的 next 指向）。




在 C++ 中，我们通常使用 struct（结构体）或 class（类）来定义一个节点。这里我用最常见的 struct 来给你演示。

1. 定义一个 C++ 节点
在 C++ 里，next 本质上是一个指针变量，它存放的是另一个 Node 在内存中的地址。

C++
struct Node {
    int data;      // 数据域：存放真正的值
    Node* next;    // 指针域：存放下一个节点的内存地址 (注意这里的 *)

    // 这是一个构造函数，方便我们创建节点时直接赋值
    Node(int val) {
        data = val;
        next = nullptr; // 现代 C++ 中，空指针用 nullptr 表示，意味着“后面没节点了”
    }
};



2. 用 next 把节点串起来
我们把刚才讲的“寻宝游戏”用 C++ 代码写出来，看看 next 是如何发挥作用的：

C++
#include <iostream>
using namespace std;

int main() {
    // 1. 创建三个独立的节点（在内存中开辟了三块小空间）
    // new 关键字会返回这块内存的地址，所以我们用指针变量接收
    Node* head = new Node(10);
    Node* nodeA = new Node(20);
    Node* nodeB = new Node(30);

    // 此时，它们是三个孤立的节点：
    // [10 | null]   [20 | null]   [30 | null]

    // 2. 用 next 指针把它们串联起来！(这就是系绳子的过程)
    head->next = nodeA;   // 让 head 的 next 指向 nodeA 的地址
    nodeA->next = nodeB;  // 让 nodeA 的 next 指向 nodeB 的地址
    // 注：nodeB->next 在创建时已经是 nullptr 了，所以链表在这里结束。

    // 此时，链表变成了：
    // [10 | *] ---> [20 | *] ---> [30 | null]

    // 3. 顺藤摸瓜：如何通过 head 拿到 30 这个数字？
    // 注意 C++ 中的箭头符号 ->，它是用来访问指针指向的对象的成员的。
    int target = head->next->next->data; 
    
    cout << "通过 head 找到的第三个节点的值是: " << target << endl;
    // 解析：
    // head->next 拿到了 nodeA
    // (head->next)->next 拿到了 nodeB
    // 最后加上 ->data 拿到了 30

    return 0;
}


完整代码
#include <iostream>
using namespace std;

// === 第一步：定义节点“图纸”和“组装机” ===
struct Node {
    int data;      // 数据域：存放真正的值
    Node* next;    // 指针域：存放下一个节点的内存地址

    // 构造函数：当我们 new 一个新节点时，自动执行这里的代码
    Node(int val) {
        data = val;         // 把传进来的数字塞进 data 抽屉
        next = nullptr;     // 默认它后面没有节点，指针设为空 (极其重要)
    }
};

int main() {
    // === 第二步：造出三个孤立的盒子 ===
    // 此时内存里是：[10 | null]   [20 | null]   [30 | null]
    Node* head = new Node(10);  // 起点：里面装着 10
    Node* nodeA = new Node(20); // 朋友小明：里面装着 20
    Node* nodeB = new Node(30); // 朋友小红：里面装着 30

    // === 第三步：把盒子串起来（系绳子） ===
    head->next = nodeA;   // 10 的线索指向 20
    nodeA->next = nodeB;  // 20 的线索指向 30
    // 注意：nodeB 在创建时 next 已经是 nullptr 了，代表链表到此结束。
    
    // 此时链表结构变成了：
    // head ---> nodeA ---> nodeB ---> nullptr
    // [10] ---> [20]  ---> [30]  ---> nullptr

    // === 第四步：顺藤摸瓜找数据 ===
    cout << "我直接看起点(head)的数字是: " 
         << head->data << endl;
         
    cout << "我顺着起点走一步(head->next)找到的数字是: " 
         << head->next->data << endl;
         
    cout << "我顺着起点走两步(head->next->next)找到的数字是: " 
         << head->next->next->data << endl;

    // === 第五步：好习惯 —— 清理内存 ===
    // 在 C++ 里，用 new 借来的内存，用完必须用 delete 还给系统
    delete head;
    delete nodeA;
    delete nodeB;

    return 0;
}
