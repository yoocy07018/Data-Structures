1.std::list<int> myList 创建一个带空头节点的双向循环链表。
        push_back()：尾插

        pop_back()：尾出

        push_front()：把数据从车头（前面）推进去。

        pop_front()：把数据从车头（前面）弹出来。


2.随机访问迭代器（Random Access Iterator）

    代表容器：std::vector

    能用语法：++it、--it、it + 3、it - 5、vec[i]。

    特点：有瞬间移动的天赋，想去哪直接加减。


3.双向迭代器（Bidirectional Iterator）

    代表容器：std::list

    能用语法：只能写 ++it 和 --it。想让list往后挪三步可用std::advance(it, 3)

    特点：没有瞬移天赋，只能一步一个脚印地“往前走”或“往后退”，绝对不能加减一个整数。


4.删除操作：精准定点清除

姿势 A：通用接住返回值写法（最推荐，全容器通用）

std::list<int> myList = {1, 2, 3, 4};

for (auto it = myList.begin(); it != myList.end(); /* 空着 */ ) {
    if (*it % 2 == 0) {
        it = myList.erase(it); // 删掉偶数，并让 it 接住下一个合法节点的指针
    } else {
        ++it;
    }
}

姿势 B：后置自增炫技写法（仅限 list / set / map 这种链式或树形容器）

for (auto it = myList.begin(); it != myList.end(); /* 空着 */ ) {
    if (*it % 2 == 0) {
        myList.erase(it++); // 💥 注意这里！
    } else {
        ++it;
    }
}
 /*后置自增的精髓：it++ 的特点是“先取值，后加 1”。

 编译器在执行这行代码时，会先偷偷把 it 当前指向的地址（比如节点 2）记录下来，准备传给 erase。

 在 erase 还没真正开始动手删人之前，it 变量已经神不知鬼不觉地执行了 ++，率先跳到了下一个节点（比如节点 3）。

 随后，erase 动手，把刚刚记录下来的那个老节点 2 彻底抹去。

 结局完美：老节点被删了，而 it 已经在轰炸开始前提前安全撤离到了下一个节点
 */
