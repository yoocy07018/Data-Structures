# 基数排序 (Radix Sort)

**核心思想：**
这是一种非比较型整数排序算法。它的原理是将整数按位数切割成不同的数字，然后按每个位数分别进行比较。通常是从最低位（个位）开始，一直处理到最高位。

---

## 1. 核心数据结构：二维数组 (桶)

为了存放每次按位拆分出来的数字，需要借助 10 个“桶”（序号为 0 到 9）。
在 C++ 中，最适合表示这种结构的容器是**二维动态数组**：
`vector<vector<int>>`

* **外层 vector:** 大小固定为 10，代表 0-9 这 10 个序号的桶。
* **内层 vector:** 容量动态变化，因为每次放到同一个桶里的数字个数是不确定的。

---

## 2. 算法执行步骤
例子：43, 47, 11, 23, 5, 57, 54, 18, 55, 38, 345, 6789
1. **确定趟数：** 找出数组中最长的数字，确定要处理的桶排序的总趟数（也就是最大数字的**位数** `len`，例如最大数是 6789，就需要循环 4 趟）。
2. **分配与收集 (核心循环)：**
   * **分配 (Distribute)：** 依次由个位开始处理，把相应位数上的数字提取出来，作为下标，将原数字放入对应序号的桶里面。
   * **收集 (Collect)：** 当所有数字都入桶完成后，再按照桶的序号 (0 -> 9)，依次取出桶里面的数据，放回原始的数组当中。
3. **完成：** 当处理完所有的位数（个位、十位、百位...直到最高位），最终放回原数组的序列就是有序的了。

---

## 3. 核心代码解析：如何提取特定位上的数字？

图片右下角给出了一段非常经典的 C++ 数学逻辑，用来在循环中依次取出数字的个位、十位、百位等。

```cpp
// 假设要处理的数字是 number，最大数字的位数是 len
int mod = 10;
int dev = 1;

// 循环 len 次，每次 mod 和 dev 都扩大 10 倍
for (int i = 0; i < len; i++, mod *= 10, dev *= 10) {
    
    // 核心公式：取出当前处理位上的数字 (0-9)
    int index = (number % mod) / dev; 
    
    // 举例说明：假设 number = 345
    // 第 1 次循环 (i=0, 个位): index = (345 % 10) / 1    = 5 / 1   = 5
    // 第 2 次循环 (i=1, 十位): index = (345 % 100) / 10  = 45 / 10 = 4
    // 第 3 次循环 (i=2, 百位): index = (345 % 1000)/ 100 = 345 / 100 = 3
    
    // 拿到 index 后，就可以执行入桶操作了：
    // bucket[index].push_back(number);
}
```
