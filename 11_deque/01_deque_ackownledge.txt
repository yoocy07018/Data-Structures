deque（双向队列，Double-ended Queue）

1 如果你想从屁股后面插数据（push_back），它就往右边（后方）开辟新公寓，让 Map 右边的格子填上地址。

如果你想从车头前面插数据（push_front），它就往左边（前方）开辟新公寓，让 Map 左边的格子填上地址。

2 📊 三大王牌序列容器终极物理对比

  容器特性            std::vector (动态数组)    std::list (双向链表)         std::deque (双向队列)
  内存物理形态          绝对连续的一大块         绝对不连续的散落节点          分段连续（多块 Buffer + 中控 Map）
  头部增删(front)      O(n)（需要全员大平移）    O(1)（改指针连线）            O(1)（往左边开辟新公寓）
  尾部增删(back)       O(1)（满时触发大搬家）    O(1)（改指针连线）            O(1)（往右边开辟新公寓）
  中间增删(insert)     O(n)（往后平移）         O(1)（仅改当前指针）           O(n)（看哪边近，平移哪边）

3 神仙级迭代器——四个指针包装出的“伪瞬移”
struct DequeIterator {
    T* cur;    // 1. 现房指针：死死指向当前正在访问的那个数据元素
    T* first;  // 2. 公寓门牌：指向当前这栋公寓（Buffer）的开头格子
    T* last;   // 3. 公寓后门：指向当前这栋公寓（Buffer）的末尾边界
    T** node;  // 4. 中控连线：一个二级指针，死死指回中控 Map 大屏幕上属于它的那个格子
};


4 在deque中执行++it
// 💥 deque 迭代器自增的底层伪代码
it.cur++; // 先往后走一格
if (it.cur == it.last) { // 🛑 越界安检：糟糕！走出当前这栋公寓的后门了！
    it.node++;          // 1. 去中控 Map 大屏幕上，把座位挪到下一栋公寓的格子上
    it.first = *(it.node); // 2. 刷新这栋新公寓的门牌开头
    it.last = it.first + 8;// 3. 刷新这栋新公寓的后门边界
    it.cur = it.first;     // 4. 终于成功住进了新公寓的第 0 个房间
}
