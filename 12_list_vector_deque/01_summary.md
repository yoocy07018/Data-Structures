# C++ 核心容器 API 知识点总结 (vector / deque / list)

本篇主要梳理 C++ 标准模板库 (STL) 中最常用的三种序列式容器：`std::vector`、`std::deque` 和 `std::list` 的核心 API、底层机制及高频考点。

---

## 0. 容器核心特性对比

| 容器 | 底层结构 | 内存连续性 | 随机访问 `O(1)` | 尾部插入/删除 | 头部插入/删除 | 任意位置插入/删除 | 迭代器类型 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **`vector`** | 动态数组 | 是 | 支持 | $O(1)$ 均摊 | $O(n)$ | $O(n)$ | 随机访问迭代器 |
| **`deque`** | 双端队列 (分段连续) | 伪连续 | 支持 | $O(1)$ | $O(1)$ | $O(n)$ | 随机访问迭代器 |
| **`list`** | 双向链表 | 否 | 不支持 | $O(1)$ | $O(1)$ | $O(1)$（需先定位） | 双向迭代器 |

---

## 1. std::vector 核心 API 总结

`vector` 是单向开口的连续线性空间（动态数组），支持快速随机访问。

### 1.1 构造与赋值
* `vector<T> v;` ：默认构造，初始化为空。
* `vector<T> v(n, elem);` ：将 `n` 个 `elem` 拷贝给容器。
* `vector<T> v(v2);` ：拷贝构造函数。
* `vector<T> v(v.begin(), v.end());` ：将区间内的元素拷贝给容器。
* `v.assign(n, elem);` ：赋值 `n` 个 `elem` 给当前容器。
* `v.assign(begin, end);` ：区间赋值（传迭代器区间）。

### 1.2 容量与大小
* `v.empty();` ：判断容器是否为空（返回 bool）。
* `v.size();` ：返回容器中当前实际元素的个数。
* `v.capacity();` ：返回容器目前的总容量（通常 $\ge size$）。
* `v.reserve(int len);` ：**预留总容量**。仅改变 `capacity`，不创建元素，用于防止多次动态扩容降低效率。
* `v.resize(int num, elem);` ：**重新指定大小**。
  * 若变长，超出部分填 `elem`（默认 0）；
  * 若变短，超出部分元素被删除。

### 1.3 数据访问
* `v[i];` ：利用下标访问，效率高，但不进行越界检查。
* `v.at(i);` ：利用索引访问，**会进行越界检查**，若越界会抛出 `out_of_range` 异常。
* `v.front();` ：返回容器第一个元素的引用。
* `v.back();` ：返回容器最后一个元素的引用。
* `v.data();` ：返回指向底层数组首地址的指针（C++11）。

### 1.4 插入与删除
* `v.push_back(elem);` ：尾部插入元素。
* `v.pop_back();` ：删除尾部元素。
* `v.insert(pos, elem);` ：在迭代器 `pos` 处插入元素，返回新元素位置的迭代器。
* `v.insert(pos, n, elem);` ：在迭代器 `pos` 处插入 `n` 个 `elem`。
* `v.erase(pos);` ：删除迭代器 `pos` 处的元素，返回下一个元素位置的迭代器。
* `v.erase(start, end);` ：删除迭代器区间 `[start, end)` 的所有元素。
* `v.clear();` ：清空所有元素（`size` 变为 0，但 `capacity` 通常保持不变）。
* `v.emplace_back(args...);` ：**原位构造**（C++11）。直接在容器尾部利用参数构造对象，避免了临时的拷贝或移动，效率高于 `push_back`。

## 2. std::deque 核心 API 总结

`deque` 是双端队列，支持头部和尾部的快速插入与删除。底层采用“中控器（map）+ 缓冲区（buffer）”的结构，表现出“伪连续”的特性。

### 2.1 独有/高频的头部操作
* `d.push_front(elem);` ：头部插入元素。
* `d.pop_front();` ：头部删除第一个元素。
* `d.emplace_front(args...);` ：头部原位构造（C++11）。

### 2.2 与 vector 类似的通用 API
* **访问**：`d[i]`、`d.at(i)`、`d.front()`、`d.back()`。
* **尾部**：`d.push_back()`、`d.pop_back()`、`d.emplace_back()`。
* **增删**：`d.insert()`、`d.erase()`、`d.clear()`。
* **大小**：`d.size()`、`d.empty()`、`d.resize()`。

> ⚠️ **重要注意点**：
> `deque` **没有** `capacity()` 和 `reserve()` 这两个 API。因为它的内存是分段拼接的，不需要也不支持像 `vector` 那样一整块连续内存的整体预留。

## 3. std::list 核心 API 总结

`list` 底层实现是双向循环链表。因为节点内存不连续，所以**不支持随机访问**（不能通过下标或 `at()` 访问）。

### 3.1 数据访问与大小
* `l.front();` / `l.back();` ：访问头尾元素的引用。
* `l.size();` / `l.empty();` ：获取大小与空状态。
* `l.resize(num);` ：重新指定链表长度。

### 3.2 插入与删除
* `l.push_back();` / `l.pop_back();` ：尾部增删。
* `l.push_front();` / `l.pop_front();` ：头部增删。
* `l.emplace_back();` / `l.emplace_front();` ：头尾原位构造。
* `l.insert(pos, elem);` ：在迭代器 `pos` 前插入元素。
* `l.erase(pos);` ：删除迭代器 `pos` 处的元素。
* `l.remove(value);` ：**按值删除**。移除链表中所有与 `value` 相等的元素。
* `l.clear();` ：清空链表所有节点。

### 3.3 链表专属成员函数
由于 `list` 的迭代器是双向迭代器，无法使用 `<algorithm>` 中的标准算法 `std::sort`（该算法要求随机访问迭代器），因此 `list` 提供了专门的成员函数：
* `l.reverse();` ：反转整个链表。
* `l.sort();` ：链表排序。默认升序，可传入自定义仿函数，如 `l.sort(greater<int>());` 降序。
* `l.merge(list& x);` ：将另一个**已排序**的链表 `x` 合并到当前链表中，合并后 `x` 为空链表。
* `l.splice(pos, list& x);` ：接合操作。将链表 `x` 的所有节点剪切并插入到 `pos` 位置，`x` 变为空。
* `l.unique();` ：去重。删除链表中**连续重复**的元素（建议先 `sort()` 再 `unique()`）。

## 4. 核心面试考点与避坑指南

### 4.1 迭代器失效问题 (Iterator Invalidation)
* **`vector`**：
  * **插入**：如果触发扩容（`size > capacity`），导致重新分配内存，**所有**迭代器、指针和引用都会失效；若未扩容，插入点及之后的迭代器失效。
  * **删除**：被删除位点及之后的迭代器都会失效。
* **`deque`**：
  * 在首尾插入或删除时，由于中控器可能扩容，可能会导致迭代器失效，但指针和引用通常仍有效；在**中间**任意位置插入或删除，**所有**迭代器、指针、引用均会失效。
* **`list`**：
  * 因为是链表结构，插入操作**绝不影响**现有迭代器；删除操作也**仅导致被删除节点的迭代器失效**，其他迭代器完全不受影响。

### 4.2 迭代器类型的限制
* `vector` 和 `deque` 属于 **随机访问迭代器 (Random Access Iterator)**。支持类似 `it + 5`、`it += 2` 以及 `it1 - it2` 的跨越式操作，也支持 `<`、`>` 比较。
* `list` 属于 **双向迭代器 (Bidirectional Iterator)**。仅支持自增自减 `it++`、`it--`，**不支持** `it + 5`，也不支持 `<` 比较（只能用 `it != l.end()`）。

### 4.3 生产环境如何选择容器？
1. 需要高效的**随机访问**（通过下标高频读取），且**尾部之外极少发生插入删除** $\rightarrow$ 选 `vector`。
2. 需要在**头部和尾部**都进行频繁的高效插入和删除（如实现自定义队列或栈） $\rightarrow$ 选 `deque`。
3. 需要频繁在**任意中间位置**执行插入和删除，且不要求随机访问 $\rightarrow$ 选 `list`。
